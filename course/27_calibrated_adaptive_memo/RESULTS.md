# CA-MeMo 真实实验结果

## 结论先行

在 72 条困难测试上，单轮 Memory 的处置准确率为 **52.78%**，且会自动接受 **83.33%** 的 OOD 案例。完整 CA-MeMo 将处置准确率提高到 **79.17%**，规则 F1 提高到 **76.39%**，OOD 误接受率降为 **0%**。它自动接受 44/72 条，覆盖率为 **61.11%**；这 44 条的处置全部正确，但其中 1 条的规则 ID 错误，因此：

- 覆盖内处置错误率为 **0%**；
- 覆盖内“处置+完整规则集”错误率为 **2.27%**。

这个结果证明了“外部校准 → 主动搜索 → 独立验证 → 必要时拒答”的流程能够显著改善安全性。但这不是新算法的论文级证据：数据是合成的，校准集只有 72 条，而且全量权威检索参考线仍明显更强。

## 校准与路由

校准正例必须同时满足“首轮处置正确”和“首轮规则集完全正确”。校准集正例率只有 **27.78%**，说明困难集确实远比第 26 课普通验证集严格。冻结后的参数为：

| 参数 | 数值 |
|---|---:|
| 低置信拒答阈值 | 0.4353 |
| 高置信直通阈值 | 0.5360 |
| 共形 `alpha` | 0.10 |
| 共形非一致性阈值 | 0.9388 |
| 测试集共形经验覆盖 | 100% |
| 测试集共形平均集合大小 | 3.00/3 |

共形集合在每个测试案例上都包含 `PASS/REVIEW/REJECT` 三个处置，因此虽然经验覆盖为 100%，却没有排除任何类别。这是明确的负结果，也是本次没有高置信直通样本的主要原因：

```text
中置信主动搜索：51/72
低置信拒答：    21/72
高置信直通：     0/72
```

因此，这次实验验证了中、低置信分支，但没有得到高置信分支的真实效果估计。若强行放宽共形条件来制造直通样本，就会在最终测试集上调参，所以本课没有这样做。

## 完整 CA-MeMo 分场景结果

| 场景 | 处置准确率 | 自动覆盖率 |
|---|---:|---:|
| 普通规则 | 91.67% | 91.67% |
| 相邻边界 | 91.67% | 83.33% |
| 无规则 / OOD | 100% | 0% |
| 多规则冲突 | 91.67% | 91.67% |
| 绑定例外 | 58.33% | 58.33% |
| 对抗改写 | 41.67% | 41.67% |

安全路由对 OOD 很有效，但代价是对抗改写和绑定例外中有较多合法或可处置案例被送去人工复核。这是 Accuracy 没有接近全量权威检索的主要原因。

## 失败案例与经验

完整 CA-MeMo 有 17 条未达到“处置+规则集完全正确”，其中 16 条是安全拒答，1 条被错误接受。代表性失败是：

1. `ca-tes-0016` 是对抗改写。金规则为 `POL-07-EVASION`，权威词面检索却选了 `POL-02-OFFSITE`。两条规则的最终处置都是 `REJECT`，所以它不会增加处置风险，但暴露了规则归因错误。
2. `ca-tes-0035` 的金规则为 `FIN-14-SYNTHETIC`，主动分支和权威词面检索都未形成可接受候选，最终正确地保守转为 `REVIEW`，但任务金处置是 `REJECT`。
3. 多个绑定例外案例的处置是 `PASS`，但低校准概率使它们在搜索前就被拒答。这表明低阈值不应只以安全负类调整，还应给允许例外保留可检索空间。

从工程上看，下一步最值得做的不是无限增加 Memory 重复采样，而是：

- 增加真实时间外校准数据，对比温度缩放、保序回归和多类校准；
- 把 BM25 替换为真正的混合检索与 reranker，特别改善对抗改写；
- 对“低置信但可能是绑定例外”单独建立安全搜索通道；
- 用真实远程权威库延迟和业务成本验证自适应路由是否值得。
