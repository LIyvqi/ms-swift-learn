# KCR-JitRL 实测结果

## 实验设置

- 回合数：每个设置 100 局；
- 随机种子：11、22、33、44、55；
- 冻结策略：本地 `Qwen3.5-0.8B-Base`，以及阿里云百炼 `qwen-plus`；
- 案例、支持和规则强度：`8 / 3 / 3`；
- 可靠支持只覆盖入口阶段，人工推荐规则只覆盖升降平台；
- 支持库额外含一条 `confidence=0.10` 的错误信息，专门用于门控鲁棒性测试；
- 没有优化器、反向传播或模型参数更新。

## 如何解释结果

本实验支持以下结论：

1. 支持知识和人工规则显著改善冷启动，使 Agent 更容易到达后续阶段并积累有效案例；
2. 案例仍然不可替代，因为两个后续阶段没有正确先验；
3. 从重复案例浓缩出的软规则提高了后期稳定性；
4. 在支持库含低可信错误信息时，置信度门控能减少负迁移；
5. 本地真实 logits 与远程 API 文本置信度得到相近趋势，说明方案不依赖开放模型权重。

同时不能把结果外推成通用 Agent 结论：当前是四阶段、三个离散候选动作的教学环境。规则浓缩与原案例共享证据，也可能在更复杂任务中过度强化偶然相关。下一步应在有任务分布变化、长工作流和留出任务的环境中继续验证。
