# 来源地图

经验 Wiki 只记录如何访问各库，不复制规则、Case 或知识正文。

| 来源 | 后端 | 层级 | 职责 |
|---|---|---|---|
| `rule_store` | `jsonl_rules` | 政策域 → 适用范围 → 路由 → 类别 → 版本 | 保存当前政策、成立条件、例外、优先级和版本。 |
| `case_store` | `sqlite_cases` | 案例域 → 业务线 → 路由 → 类别 → 结论 | 保存训练集和未来人工复核的相似边界案例。 |
| `knowledge_store` | `directory_knowledge` | 知识域 → 知识族 → 业务线 → 路由 → 类别 → 文档类型 | 保存风险概念、黑话别名、背景解释和边界知识。 |
