# 第 29 课真实实验结果

正式结果来自 2026-08-15 的干净重训：从 `Qwen3.5-0.8B-Base` 开始，不载入任何旧检查点，
用 2020 对数据严格训练两轮。硬件为单张 AMD MI308X 约 191.7 GiB，框架为官方 ms-swift
`v4.4.3` 标签源码。分类策略固定为第 28 课 Brier-RLCR `checkpoint-100`，Verifier 与它参数独立。

## 训练结果

| 项目 | 结果 |
|---|---:|
| 训练数据 | 2020 对 |
| 验证数据 | 420 对 |
| 轮次 / 更新步 | 2 / 128 |
| 可训练参数 | 752.39M（88.21%） |
| 训练 batch / 验证 batch | 32 / 16 |
| 训练用时 | 471.6 秒 |

| 第一轮验证准确率 / loss | 98.38% / 0.05586 |

验证准确率没有继续增加，但 pairwise loss 继续下降，说明第二轮主要增大 chosen/rejected 间隔。
最终验证平均 `score(chosen)-score(rejected)` 为 8.614。

## 连接真实策略预测

策略在 160 条 ID 测试新闻上答对 157 条，Accuracy 为 98.13%。下表比较策略自报置信度和
独立 Verifier。阈值在 160 条 ID 校准加 100 条 OOD 校准上选择，约束联合风险不超过 5%。

| 置信来源 | ID ECE↓ | ID Brier↓ | ID NLL↓ | ID AURC↓ | 对错 AUROC↑ | ID 覆盖率 | 覆盖内风险 | OOD 错误接受率↓ |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 策略自报原值 | 0.0813 | **0.0250** | 0.1466 | 0.01869 | 0.5000 | 0% | 不适用 | 0%* |
| 策略自报 + ID Platt | **0.0126** | **0.0186** | **0.1015** | 0.01869 | 0.5000 | 0% | 不适用 | 0%* |
| 独立 Verifier 原值 | 0.0336 | 0.0304 | 0.1225 | **0.00148** | **0.9363** | **96.88%** | **1.29%** | **6%** |
| 独立 Verifier + 联合 Platt | 0.0432 | 0.0399 | 0.1766 | **0.00148** | **0.9363** | **96.88%** | **1.29%** | **6%** |

星号不是优势：自报置信度在 ID/OOD 上几乎固定，校准集无法找到既满足 5% 风险又有至少 10%
覆盖的阈值，只能回退到阈值 1.0，结果是拒绝所有 ID 和 OOD。它的 OOD 错误接受率虽然为 0，
自动覆盖率也为 0，业务上不可用。

独立 Verifier 将逐样本对错 AUROC 从 0.5 提升到 0.9363，AURC 降低 92.1%。它在接受
155/160 条 ID 预测时只有 2 条错误，同时只误接受 6/100 条 OOD。相比恢复版的 AUROC 0.9119、
OOD 错误接受率 7%，干净两轮训练也得到更好的正式结果。

ID 单独看时，自报置信度的 Brier 更小，因为策略几乎全对且固定报 0.90；这不能证明它能识别
哪条会错。独立 Verifier 的核心提升在排序、选择性预测和开放集检测，不应把指标换成只看最有利
的一项。

## 260 条 ID+OOD 联合测试

把 160 条 ID 与 100 条 OOD 放在同一个实际流量口径中，OOD 的 `target_correct` 记为 0：

| 置信来源 | 联合 ECE↓ | 联合 Brier↓ | 联合 NLL↓ | 联合 AUROC↑ | 总覆盖率 | 覆盖内风险 |
|---|---:|---:|---:|---:|---:|---:|
| 策略自报原值 | 0.2962 | 0.3269 | 0.9758 | 0.5000 | 0% | 不适用 |
| 策略自报 + ID Platt | 0.3900 | 0.3913 | 2.0192 | 0.5000 | 0% | 不适用 |
| 独立 Verifier 原值 | 0.0358 | 0.0346 | 0.1335 | **0.9923** | 61.92% | 4.97% |
| 独立 Verifier + 联合 Platt | **0.0296** | **0.0284** | **0.1246** | **0.9923** | 61.92% | 4.97% |

联合测试更符合本课目标：Verifier 必须同时判断四分类候选是否正确以及新闻是否根本不属于目标
集合。Platt 在联合分布上有效改善 ECE/Brier/NLL，但在纯 ID 子集上反而变差，因为校准集中加入
了 100 个 OOD 负例。部署时应按真实 ID/OOD 基率准备校准集，而不是复用本课的固定比例。

## 推理成本

每条策略预测做两次完整序列前向，分别给 `CORRECT` 和 `INCORRECT` 打分。本机 batch 32 的
实测均摊结果：

- 两次前向合计平均 784.29 个输入 token；
- 两次前向合计平均 0.0234 秒；
- 不产生额外生成 token。

这个延迟是 MI308X 上批量推理的均摊值，不能直接当成单请求在线延迟。若服务端支持直接读取
单值 reward head，可以批量拼接两个 verdict；若只能调用普通生成 API，就不能直接使用本地
score head，需要另训生成式判别器或部署本课 RM。

## 显存与失败实验

我们真实尝试了多个 batch，而不是根据空闲显存猜参数：

| 训练 batch | 结果 | 观察 |
|---:|---|---|
| 128 | OOM | 首步接近 185 GiB |
| 96 | OOM | 首步接近 186 GiB |
| 64 | OOM | 第 12 步碎片化，训练日志峰值约 169.1 GiB |
| 48 / 验证 128 | OOM | 第一轮可训练，验证切回第二轮失败 |
| 48 / 验证 32 | 可恢复实验 | 第一轮验证 98.83%，但变更 batch 后恢复不构成严格两轮 |
| **32 / 验证 16** | **稳定** | 干净完成 128 步，峰值 89.41 GiB |

曾从 batch 48 的第 40 步参数检查点改用 batch 32 续跑，得到了有效但样本跳过位置有歧义的恢复
模型。它没有作为正式结果。正式模型重新从 Base 开始，训练日志的 128 步全部使用同一个 batch。

## 结论与边界

1. 这条训练路线确实有效：独立参数模型显著提升对错排序和 OOD 检测，不是提示词自评。
2. 第 28 课 Brier-RLCR 更擅长改善封闭集总体校准；第 29 课 Verifier 更擅长逐样本选择和开放集拒绝。
3. 独立模型要付出约一倍模型存储和两次前向成本，但可以复用于多个分类策略，也更容易独立审计。
4. 当前 OOD 类别仍来自同一复旦新闻语料，不等同于跨来源、跨时间、对抗输入的真实生产 OOD。
5. 训练负例是固定相邻错类。后续可用策略实际犯错轨迹做 hard-negative mining，再比较是否进一步
   降低 6% 的 OOD 错误接受率。

完整逐条轨迹位于本机 `outputs/29_independent_confidence_verifier/evaluation_clean/`，包括模型
指纹缓存、原始两个奖励、差值、原始/校准置信度、阈值和资源统计。该目录被 Git 忽略；仓库提交
训练脚本、固定数据、校验和与本报告。
